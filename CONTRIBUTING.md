# Contributing

Thanks for taking a look. This is a small, dependency-free personal portfolio.

1. Open an issue for a substantial change so its direction can be discussed. Small bug fixes can go straight to a pull request.
2. Fork the repository and create a branch for one focused change.
3. Run `npm run dev`, then make changes in `dist/`.
4. Run `npm run check` and `npm test` with Node.js 22 or newer.
5. For visible changes, check both themes, a narrow phone viewport, keyboard use, reduced motion and the footer pause control. Include before/after screenshots when useful.
6. Explain the problem, your change and how you checked it in the pull request.

Keep the reading column calm and readable. Preserve accessible labels, visible focus, touch scrolling and motion preferences. Avoid new dependencies unless there is a clear need. Never add API keys, credentials, personal data or private deployment configuration.

New artwork must have documented permission to redistribute it. Include provenance and any required notices. The existing PNG illustrations were generated with GPT Image 2.5; use that model if adding matching generated art, or clearly document a different origin. Project placeholders must not become invented achievements.

By submitting a contribution, you agree that your contribution may be distributed under this project’s MIT license, while identified third-party material keeps its own license. No contributor license agreement is required.
